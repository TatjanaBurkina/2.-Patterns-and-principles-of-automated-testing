# 🧩 Composite Pattern Implementation (Паттерн «Компоновщик» / Составной узор)

Учебный Java-проект, демонстрирующий реализацию структурного паттерна проектирования **«Компоновщик» (Composite Pattern)**. Паттерн позволяет сгруппировать объекты в древовидную структуру для представления иерархии «часть-целое» и работать с отдельными объектами и группами объектов одинаково.

---

## 📂 Структура проекта

Проект организован по стандартам сборщика Maven и содержит следующие компоненты:

```text
├── src/
│   ├── main/java/com/example/        # Основной код приложения
│   │   ├── App.java                  # Главный класс (точка входа)
│   │   ├── Component.java            # Общий интерфейс или абстрактный класс компонента
│   │   ├── Composite.java            # Составной компонент (контейнер, содержащий дочерние элементы)
│   │   └── Leaf.java                 # Листовой компонент (конечный элемент без потомков)
│   └── test/java/com/example/        # Модульные тесты (JUnit)
│       ├── AppTest.java              # Тесты приложения
│       ├── Composite.java            # Тестовые вспомогательные файлы / реализации
│       └── CompositeTest.java        # Юнит-тесты для проверки паттерна Composite
├── target/                           # Директория скомпилированных файлов и отчетов Maven
└── pom.xml                           # Конфигурация сборщика Maven и зависимостей
